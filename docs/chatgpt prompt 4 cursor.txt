# 8. BOOKING-REQUEST PLUGIN

Create a separate plugin:

`watphou-bookings`

The PDF did not originally require direct booking/payment, but the following newer requirement supersedes that omission.

## Required workflow

This is “request first, pay later”:

1. Customer selects a tour.
2. Customer submits dates, participants and contact details.
3. The system creates a booking request.
4. Staff checks availability.
5. Staff confirms the final details and amount.
6. Staff clicks a button to create/send the payment link.
7. Customer pays through BCEL.
8. A verified BCEL callback updates the booking.
9. Customer and staff receive confirmation.

## Booking fields

Include:

* Unique booking reference
* Selected tour
* Preferred date
* Alternative date
* Number of adults
* Number of children and ages
* Customer name
* Email
* Phone
* WhatsApp
* Country
* Preferred language
* Pickup location/hotel
* Accommodation preference
* Guide preference
* Customer message
* Staff notes
* Quoted amount
* Currency
* Payment expiration
* Privacy consent
* Creation and modification timestamps
* Audit history

## Booking states

Implement a controlled state machine:

* `requested`
* `under_review`
* `availability_confirmed`
* `quote_sent`
* `payment_pending`
* `paid`
* `confirmed`
* `rejected`
* `expired`
* `cancelled`
* `refunded`
* `payment_failed`

Prevent invalid transitions.

Record who changed each status and when.

## Manager booking screen

The manager must be able to:

* See new booking requests
* Filter by date, tour, customer and status
* Open a request
* Add internal notes
* Confirm availability
* Adjust/finalize the quote
* Set payment-link expiration
* Send or resend a payment link
* Copy a prepared WhatsApp message
* Send an email
* Mark a manually verified payment with a reason
* Cancel or reject a request
* Export an appropriate booking list
* Never see or store card details

Use nonces, capability checks, validation, sanitization and escaping throughout.

Protect personal information and never expose booking records through public WordPress APIs.
