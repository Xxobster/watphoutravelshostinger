# Glossary — Watphou Travels

Terms used in this project. Full words first; acronyms in parentheses where helpful.

| Term | Meaning |
|------|---------|
| **Bolaven Plateau** | Highland region in southern Laos; waterfalls, coffee plantations, cool climate |
| **Vat Phou** (Wat Phou) | UNESCO World Heritage Khmer temple complex near Champasak |
| **Si Phan Don** | "4000 Islands" — Mekong river island region in southern Laos |
| **Champasak** | Province and town near Vat Phou |
| **Pakse** | Main city in southern Laos; Watphou Travels base |
| **BCEL** | Banque pour le Commerce Extérieur Lao — Lao bank; future online payment provider |
| **Polylang** | Free WordPress plugin for multilingual sites |
| **WP-CLI** (WordPress Command Line Interface) | Command-line tool to manage WordPress on the server |
| **CPT** (Custom Post Type) | WordPress content type beyond default posts/pages — e.g. `tour` |
| **Gutenberg** | WordPress block editor |
| **Block theme** | Theme built for full-site editing with blocks and `theme.json` |
| **Mu-plugin** (Must-Use plugin) | Auto-loaded plugin from `wp-content/mu-plugins/` |
| **HTTP Basic Authentication** | Browser username/password gate before the site loads |
| **hreflang** | HTML attribute telling search engines about language variants of a page |
| **noindex** | Directive telling search engines not to index a page |
| **301 redirect** | Permanent redirect from old URL to new URL |
| **410 Gone** | HTTP status meaning content permanently removed |
| **REST API** (Representational State Transfer Application Programming Interface) | WordPress JSON API — booking data must not be exposed here |
| **Yoast SEO** | Free WordPress search-engine optimization plugin |
| **Petit Futé** | French travel guide; Watphou has reviews there (text not yet imported) |
| **VPS** (Virtual Private Server) | Remote Linux server `sm`. Watphou demo was removed from it on 2026-09-10 |
| **Hostinger** | Current WordPress host. Staging URL is the temporary `*.hostingersite.com` domain |
| **Bluehost** | Former production-host plan; superseded by Hostinger |
| **DuckDNS** | Free dynamic DNS; `smbistro.duckdns.org` still belongs to the restaurant app on `sm` — do not use for Watphou |
| **Wix** | Current website platform being replaced |
| **Tour Manager** | Custom WordPress role for non-technical staff |
